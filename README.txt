LRnote — личный учебный планировщик

Что внутри:
- расписание ИС-28 (первая подгруппа; показываются только предметы и время);
- недельный просмотр;
- добавление домашнего задания к конкретной паре;
- сроки, отметка выполнения;
- прикрепление фото и файлов;
- светлая и тёмная темы;
- локальное сохранение данных в браузере.

Как установить на iPhone:
1. Разместить содержимое папки на HTTPS-хостинге (например, GitHub Pages).
2. Открыть опубликованный адрес в Safari.
3. Нажать «Поделиться» → «На экран Домой».
4. Если появится переключатель «Открывать как веб-приложение», включить его.
5. Нажать «Добавить».

Важно:
- Для первого размещения GitHub Pages потребуется создать аккаунт GitHub и загрузить файлы. Это можно сделать с iPhone через Safari.
- Данные и вложения сохраняются локально в хранилище браузера на этом устройстве. Не очищайте данные сайта, иначе записи могут удалиться.
- Это первая версия прототипа, не нативное приложение App Store.
- Сделайте резервные копии важных файлов отдельно.
